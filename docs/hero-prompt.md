# Hero image generation prompt

Use with Midjourney / DALL·E / Ideogram / Flux. Target: README banner,
wide format (16:9 or 21:9), save as `assets/hero.png`, then uncomment the
`<img>` tag at the top of README.md.

---

## Prompt

> A charming fluffy llama wearing tiny round glasses, sitting at a cozy
> desk at night, typing on a vintage mechanical keyboard in front of a
> dark-themed terminal showing green Vim code with faint grey "ghost text"
> completing a line. Warm desk lamp glow against a deep navy/Catppuccin
> color palette (#1e1e2e background, mauve and green accents). A small
> ethernet cable on the desk is visibly UNPLUGGED, with a subtle
> "offline" vibe — everything runs locally. Flat vector illustration,
> soft gradients, subtle film grain, wide banner composition with empty
> space on the right for a title, playful open-source mascot style,
> high detail, no text, no words, no letters.

**Aspect ratio:** 21:9 (Midjourney: append `--ar 21:9 --style raw`)

## Variations

- Pixel-art version: replace style clause with "16-bit pixel art, crisp
  pixels, CRT scanline glow".
- Minimal version: "minimal line-art logo, single accent color, white
  background" (good for a light-mode logo).
